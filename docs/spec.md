# SousChef 仕様書

インタビュー形式で順次決定した仕様を記録する。決定には ID（D-xx）を振る。
変更する場合は行を消さず「~~旧決定~~ → 新決定（変更日・理由）」の形で残す。

## 1. 前提・利用者

- 利用者: 夫婦2人（1世帯のみ。複数世帯対応は当面不要）
- 利用形態: iPhone の PWA（ホーム画面に追加して使用）
- UI 言語: 日本語

| D-54 | ご飯と麺         | 提案時の条件（D-34）に「ご飯: 炊いてある / 炊いてない」を足し、インタビュー（D-53）の「在庫のみ / 買い足し OK」の次に聞く。初期値は前回の答え（初回は「炊いてある」）。炊いてあるときは、ご飯に合う主菜・副菜・汁物にするよう AI に伝える（主食のレシピは出さない）。炊いてないときは次に麺を「うどん / パスタ / そば」から 1 つ選ぶ。選んだ麺を使った料理を主菜にし、3 案とも同じ麺。副菜・汁物はそれに合わせる。麺を選んだときは「副菜: あり / なし」も聞く（なしなら副菜のレンジは聞かない。副菜・汁物とも、なしなら麺料理 1 品）。麺の選択肢は D-20 に従い、在庫のみのときは在庫（カテゴリ「主食」の食材名で判定）にある麺だけを出し、1 つもなければ「主食なし」で提案する。買い足し OK なら 3 つとも出し、在庫にない麺は買い足しにする                                                                                                                                                                                                                                                                                                                  |
| D-63 | 提案の速さ       | 献立提案（D-19。「別の案を出す」を含む）を 2 段階にして待ち時間を短くする。① まず 3 案の料理名・材料名・合計時間・期限が近い食材だけを作り、すぐ案の一覧に出す（分量・手順・段取りのコツはまだない） ② 一覧を出したらすぐ、裏で 3 案のレシピ（分量・手順・各料理の時間・段取りのコツ）を 1 案ずつ同時に作り、できた案から埋める。レシピがまだの案も「レシピを見る」で開け、料理名と材料名に「レシピを作っています…」を添え、できたらそのまま分量・手順を出す。★保存・「作った」はその案のレシピができるまで押せない。レシピ作りが失敗した案や、作っている途中でアプリを閉じて開き直した案には「レシピを作る」を出し、その案だけ作り直す（料理名は変えない）。回数上限（D-21）は ① だけを 1 回と数え、② と作り直しは数えない。提案された料理の履歴（D-51）には、レシピができた案の料理をそのときに記録する。目安は案の一覧が出るまで今の半分以下（2026-10-30 決定: 利用者の要望）                                                                                                                                                                             |
